# `scrollback_lines = 1000000`

How many lines of scrollback you want to retain.

Wezmux defaults to 1,000,000 lines (upstream WezTerm defaults to 3500) so that long-running AI agent sessions keep their full history. Lower this if you run on very memory-constrained hardware.
